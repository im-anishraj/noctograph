# Roadmap

Nactograph is early, but the direction is clear: make AI-agent coding sessions inspectable, safe to share, and useful during review.

## v0.1.x - Polish and Contributor Onboarding

- Improve documentation, examples, and issue templates.
- Add small, well-scoped contributor tasks.
- Tighten install, smoke test, and release confidence.
- Improve report copy, empty states, and accessibility.

## v0.2.0 - Recorder Reliability

- Improve PTY behavior across Windows, macOS, and Linux.
- Better signal handling, terminal resize support, and long-session behavior.
- More precise git snapshotting for renames, binary files, and ignored paths.
- Stronger fixtures for shell and filesystem edge cases.

## v0.3.0 - Risk and Security Depth

- Expand risk rules and evidence quality.
- Reduce false positives with clearer rule thresholds.
- Improve redaction audits and custom pattern ergonomics.
- Add more security-focused tests and fixtures.

## v0.4.0 - Integrations and Ecosystem

- GitHub PR comment workflows.
- CI artifact upload examples.
- More examples for Codex and other coding agents.
- Programmatic consumption patterns for the JSONL event stream.

## Future Research

- Session comparison across agent runs.
- Team policy packs for risk rules.
- Optional report signing or provenance metadata.
- Import/export tools for external observability systems.

# Support

Use the right channel so maintainers and contributors can help quickly.

## Questions and Ideas

Use GitHub Discussions for:

- usage questions
- workflow ideas
- integration ideas
- examples from agent sessions
- early design feedback

## Bugs and Feature Requests

Use GitHub Issues for:

- reproducible bugs
- feature requests with a clear user need
- documentation gaps
- test coverage gaps
- contributor tasks

## Security

Use [SECURITY.md](SECURITY.md) for vulnerabilities or secret-leak concerns. Do not post sensitive logs, `.env` files, tokens, or private session captures in public issues.

## Before Asking

Please include:

- Nactograph version
- Node version
- operating system
- command you ran
- redacted report or JSONL excerpt, if useful
